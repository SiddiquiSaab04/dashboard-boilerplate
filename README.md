# 🚀  Dashboard Boilerplate

A professional, high-performance dashboard boilerplate built with **React**, **TypeScript**, and **Vite**. This template is designed to provide a robust foundation for building scalable administrative interfaces with a focus on speed, reusability, and modern aesthetics.

## 🎯 Purpose

The goal of this boilerplate is to accelerate the development of modern web dashboards by providing a set of pre-configured, generic, and highly customizable UI components. It follows best practices in React development, ensuring type safety with TypeScript and styling flexibility with Tailwind CSS.

## 🛠️ Key Features

### 🧩 Generic Components
Build consistent UIs faster with our suite of atomic and molecular components:

*   **📊 Dynamic Table**: A powerful data table component powered by `react-data-table-component`, featuring custom styling, pagination, and row-click interactions.
*   **📝 Flexible Forms**: A generic form builder that handles various input types (Text, Textarea, Select, Checkbox, etc.) with support for left/right icons and layout configurations.
*   **🪟 Interactive Modals**: A premium modal system with backdrop blur, smooth entry animations, and configurable headers/footers.
*   **📇 Elegant Cards**: Versatile card components for grouping content, featuring customizable icons and elevation styles.
*   **🏷️ Semantic Headings**: A dedicated `Title` component for standardized page headers with support for icons and descriptions.
*   **🖱️ Custom Buttons**: Reusable button components with various state handling (loading, disabled) and styling options.
*   **💀 Reusable Skeletons**: Comprehensive loading placeholder system (`Skeleton`, `SkeletonText`, `SkeletonAvatar`, `SkeletonMetricCard`, `SkeletonCard`, `SkeletonTable`, `SkeletonForm`) with both smooth shimmer (wave) and pulse animations.

### 🏗️ Layout Structure
Our layout is designed for maximum usability and responsive control:

*   **⚡ Navigation Bar**: A fixed top navigation bar for global actions and identity.
*   **📂 Sidebar**: A persistent sidebar for intuitive application-level navigation.
*   **🖼️ Main Content Area**: A template-wrapped main area that ensures consistent padding and spacing across all pages.
*   **📦 Template Wrapper**: A specialized wrapper component that simplifies page-level layout management.
*   **🔔 Notifications**: A notification system with smooth entry animations.

## 🚀 Tech Stack

- **Core**: React 19 + TypeScript
- **Build Tool**: Vite 8
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Data Management**: Axios
- **Notifications**: Sonner
- **Routing**: React Router 7

## 🚦 Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
